# Foxy Proxy для Windows

Распакуйте архив полностью. Откройте папку под свой тип системы и запустите `FoxyProxy.exe`. Тип системы указан в «Параметры → Система → О системе».

- `Windows-x64` — 64-разрядные процессоры Intel и AMD.
- `Windows-x86` — 32-разрядная Windows 10.
- `Windows-ARM64` — процессоры ARM64.

Сборки рассчитаны на Windows 10 и 11. Среда .NET уже в комплекте. Если для входа требуется Microsoft Edge WebView2 Runtime, запустите `MicrosoftEdgeWebview2Setup.exe` из корня распакованного архива при подключённом интернете.

1. Нажмите «Войти через Firefox». Введите почту и пароль на странице Mozilla в открывшемся окне. Завершите подтверждение по подсказкам Mozilla.
2. Нажмите «Обновить пинг», чтобы загрузить серверы Mozilla и измерить задержку TCP до каждого. В списке сначала идут серверы с меньшей задержкой. Выберите сервер или оставьте «Автоматически».
3. Выберите «Локальный SOCKS5» или «Весь ПК» и нажмите круглую кнопку питания. Для режима «Весь ПК» подтвердите запрос Windows на права администратора.
4. Ещё раз нажмите кнопку питания или закройте окно, чтобы отключить прокси.

В локальном режиме задайте адрес `127.0.0.1:1080` и тип SOCKS5 в нужном приложении. Если в настройках есть опция удалённого разрешения DNS через SOCKS5, включите её для запросов этого приложения.

В карточке «Трафик за подключение» видны общий объём, полученные и отправленные данные через прокси. Значения обновляются каждую секунду и остаются видны после отключения до следующего подключения или закрытия окна. 1 ГБ равен 1 000 000 000 байт.

Режим «Весь ПК» направляет TCP и DNS через виртуальный адаптер. UDP, кроме DNS, и ICMP блокируются. Приложения, которым нужен UDP, могут потерять часть функций. Служебные соединения клиента с Mozilla идут напрямую, чтобы подключение могло работать и обновляться.

Вы вводите пароль на странице Mozilla в приватном окне WebView2. Приложение хранит сессию в `%LOCALAPPDATA%\FoxyProxy\session.dat` с шифрованием Windows DPAPI. Запуск из другой папки или новой копии архива использует ту же сессию в профиле текущего пользователя Windows. Кнопка «Выйти из аккаунта» удаляет локальную сессию.

Код прокси основан на [firefox-vpn-client](https://github.com/UjuiUjuMandan/firefox-vpn-client/tree/c1c5d895a2c52c69a9e06e672eae5074c9cc3fa1). Виртуальный адаптер обслуживает отдельный процесс [sing-box 1.14.4](https://github.com/SagerNet/sing-box/tree/v1.14.4). Его лицензия находится в папке `tun` рядом с приложением.

Вход и оформление адаптированы из [FoxyVPN](https://github.com/Vauth/FoxyVPN/tree/0e344de67dea1df370342d354bb6240b50201abc). Условия лицензии MIT приведены в `LICENSE.FoxyVPN`.

Для сборки из исходников установите Go 1.25 или новее и .NET SDK 10. Из корня репозитория выполните `powershell -ExecutionPolicy Bypass -File scripts/build-desktop.ps1`. Скрипт проверяет SHA-256 компонента sing-box и подпись установщика WebView2, затем создаёт `dist/FoxyProxy-Windows.zip`. Путь к другой папке можно передать через `-OutputDirectory`.
